ЛизингПро — статическая версия (HTML/CSS/JS)
=============================================

ФАЙЛЫ:
  index.html          — разметка сайта
  styles.css          — стили
  script.js           — логика (меню, калькулятор, отправка формы)
  assets/hero-fleet.jpg — фон для hero-секции

КАК ЗАПУСТИТЬ:
  Просто откройте index.html в браузере, либо загрузите все файлы
  на любой хостинг (Beget, Reg.ru, Netlify, Vercel, GitHub Pages и т.д.).

НАСТРОЙКА ОТПРАВКИ ЗАЯВОК НА ВАШУ ПОЧТУ (FORMSPREE):
  1. Зарегистрируйтесь на https://formspree.io
     (бесплатный план: 50 заявок в месяц)
  2. Создайте новую форму («New Form»), укажите вашу почту,
     на которую должны приходить заявки.
  3. Скопируйте ID формы из URL — это последняя часть после /f/.
     Пример: https://formspree.io/f/xayzgkqw  →  ID: xayzgkqw
  4. Откройте файл script.js в любом редакторе.
  5. Найдите вверху строку:
        const FORMSPREE_ENDPOINT = "https://formspree.io/f/YOUR_FORM_ID";
     и замените YOUR_FORM_ID на ваш ID. Сохраните файл.
  6. Первая отправка с настоящего домена потребует подтверждения
     по e-mail (Formspree пришлёт письмо).

Готово — данные заявок (имя, телефон, email, категория, комментарий)
будут приходить на указанную почту.
